# v1.0 - Point-in-time validation and catalyst research

This release publishes the current StockPicking pipeline and preserves its
original August 19 baseline. It includes the research corrections and data-source
extensions made since that baseline.

## Changes

- Audit feature timestamps and retain immutable trial-registry snapshots.
- Anchor catalyst events to trading sessions and estimate model fallbacks using
  training data only.
- Select short trades within each test year, isolate the legacy holdout, execute
  explicit signals, and apply company exposure once.
- Require provenance for prospective rankings and omit realized outcomes from
  ranking exports.
- Add GitHub catalyst/date imports, Stooq price recovery, source inventories,
  and expanded ablation and robustness reports.

## Research status

The saved short-edge report describes 59 development out-of-sample predictions
and 15 selected short trades. Its verdict remains **promising but unvalidated**.
The current sample is small, historical trial snapshots are incomplete, and the
previously inspected evaluation periods cannot serve as a pristine final holdout.
See [the audit](../../reports/CODE_AND_EDGE_AUDIT.md) and
[short-edge report](../../reports/SHORT_EDGE_VALIDATION.md).

## Validation

- `python -m pytest -q`: **71 passed** on September 27, 2026, using the local
  Anaconda Python environment.
- This publication did not rerun data acquisition, model training, or backtests.
- Existing tracked research snapshots are included. Ignored working databases,
  raw/intermediate files, downloaded GitHub datasets, and local caches remain
  outside the release. Fetch external GitHub datasets with
  `python -m src.cli seed-github-data` when needed.
